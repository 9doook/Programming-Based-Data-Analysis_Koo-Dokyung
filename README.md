# GSE159984: 제2형 당뇨병 췌도 전사체 분석

## 1. 프로젝트 개요 (Project Overview)

본 프로젝트는 NCBI Gene Expression Omnibus(GEO)에 공개된 GSE159984 데이터를 활용하여 제2형 당뇨병(Type 2 Diabetes Mellitus, T2D)과 인간 췌도(human pancreatic islets)의 유전자 발현 변화 사이의 연관성을 분석합니다.

주요 목적은 T2D 환자의 췌도에서 나타나는 차등 발현 유전자(Differentially Expressed Genes, DEGs)를 확인하고, 이를 포도당(Glucose) 및 팔미트산(Palmitate)에 의한 대사 스트레스 조건의 유전자 발현 변화와 비교하는 것입니다.

## 2. 연구 질문 (Research Questions)

본 프로젝트에서는 다음 질문을 중심으로 분석을 수행합니다.

1. T2D 환자의 인간 췌도에서 어떤 유전자들이 차등 발현되는가?
2. T2D와 관련된 유전자 발현 변화는 어떤 생물학적 경로(Biological Pathways)와 연관되어 있는가?
3. T2D 관련 유전자 발현 변화는 포도당과 팔미트산의 복합 대사 스트레스 조건에서도 관찰되는가?
4. 포도당 단독, 팔미트산 단독, 복합 처리 조건 사이에는 어떤 유전자 발현 차이가 나타나는가?

## 3. 공개 데이터 출처 (Public Data Source)

- 데이터베이스: NCBI Gene Expression Omnibus (GEO)
- 데이터셋: GSE159984
- 원본 데이터 페이지: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE159984

### 분석 입력 파일

| 파일명 | 비교 조건 |
|---|---|
| `GSE159984_de-t2d.tsv.gz` | T2D vs Control |
| `GSE159984_de-d4pg.tsv.gz` | Palmitate + Glucose |
| `GSE159984_de-d4p.tsv.gz` | Palmitate |
| `GSE159984_de-d4g.tsv.gz` | Glucose |

**데이터 활용 범위**

본 프로젝트는 원시 RNA-seq 데이터(FASTQ 또는 raw count)로부터 차등 발현 분석을 새롭게 수행하는 프로젝트가 아닙니다.

GEO에 공개된 기존 차등 발현 분석 결과 테이블을 다운로드하여, 유전자 필터링, 결과 시각화, 경로 분석 및 조건 간 비교를 수행하는 2차 분석(Secondary Analysis) 프로젝트입니다.

## 4. 분석 과정 (Analysis Workflow)

1. NCBI GEO에서 공개 분석 파일 다운로드
2. 입력 파일의 무결성 및 데이터 구조 검증
3. 일관된 기준에 따른 차등 발현 유전자 선별
4. T2D 관련 유전자 발현 변화 시각화
5. 생물학적 경로 풍부도 분석(Pathway Enrichment Analysis)
6. T2D와 포도당·팔미트산 복합 스트레스 조건 간 공통 유전자 탐색
7. 포도당 단독, 팔미트산 단독 및 복합 스트레스 조건 비교
8. 자동화 테스트 및 재현성 검증

## 5. 차등 발현 유전자 선별 기준 (DEG Filtering Criteria)

초기 분석 기준은 다음과 같습니다.

- 보정 p-value (`padj`) < 0.05
- 절대 로그2 배수 변화량 (`|log2FoldChange|`) > 0.58

위 기준을 충족하는 유전자를 차등 발현 유전자로 분류합니다.

분석 기준은 설정 파일에서 변경할 수 있도록 구성하여, 동일한 기준을 여러 입력 데이터에 일관되게 적용할 수 있도록 설계합니다.

## 6. 재현성 및 검증 (Reproducibility and Validation)

본 프로젝트는 특정 컴퓨터 환경에 종속되지 않고 다른 Python 환경에서도 실행할 수 있도록 구성하는 것을 목표로 합니다.

이를 위해 다음 항목을 검증합니다.

- 입력 데이터 파일의 무결성
- 필수 컬럼 및 데이터 형식
- 결측값 및 중복 유전자 확인
- DEG 필터링 함수의 단위 테스트
- 조건 간 유전자 병합 및 비교 결과 검증
- 동일한 입력과 분석 조건에서의 결과 일관성
- 주요 분석 단계의 오류 및 예외 상황 검증

테스트 결과와 검증하지 못한 항목은 별도로 기록합니다.

## 7. 해석상의 주의점 및 한계 (Limitations)

본 프로젝트는 인간 췌도 조직의 Bulk Transcriptomic Data를 활용합니다.

따라서 다음 사항에 주의해야 합니다.

- 관찰된 유전자 발현 변화가 췌도 내 베타세포에서만 발생했다고 단정할 수 없습니다.
- T2D와 대사 스트레스 조건 사이의 공통 유전자 발현은 연관성을 보여줄 뿐, 인과관계를 증명하지 않습니다.
- Pathway Enrichment 결과는 특정 생물학적 경로에 속하는 유전자가 풍부하게 나타나는지를 보여주며, 해당 경로의 실제 활성도를 직접 측정한 것은 아닙니다.
- 포도당과 팔미트산의 복합 처리 결과만으로 두 요인의 통계적 상호작용이나 상승 효과를 입증할 수 없습니다. 이를 검증하려면 별도의 상호작용 분석 모델이 필요합니다.
